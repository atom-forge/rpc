# Rpc

Az Rpc egy full-stack RPC (Remote Procedure Call) keretrendszer TypeScript projektekhez. Leegyszerűsíti a kliens és a szerver közötti kommunikációt azáltal, hogy típusbiztos API-t biztosít. **Keretrendszer-független** — bármilyen Node.js vagy edge futtatókörnyezettel működik (SvelteKit, Express, Hono, Next.js, Nuxt, stb.).
